## 1. 蒙特卡洛方法

对应考纲：**"Python程序设计方法"**（蒙特卡洛计算方法）。常与 `random` 库结合出综合编程题。

### 什么是蒙特卡洛方法

- **蒙特卡洛方法（Monte Carlo method）**：又称**随机采样方法 / 统计模拟方法**，利用**随机数**（或伪随机数）来求解问题的近似解
- 核心思想：当问题的解难以精确计算时，构造一个与解相关的**随机试验**，大量重复试验后，用**事件发生的频率近似代替概率**，从而得到问题的数值近似解
- 名字来源：摩纳哥赌场 Monte Carlo（摩纳哥是法国的"保护国"或"附庸"）
- 特点：
  - 得到的是**近似解**，不是精确解；试验次数越多，结果一般越接近真值（大数定律）
  - 每次运行结果可能略有不同（除非固定随机种子 `random.seed()`）
  - 把"确定性难题"转化为"随机试验统计"，实现简单

### 经典例子：投点法求 π

**原理**：边长为 `r` 的正方形内切一个 1/4 圆（半径 `r`）：

- 正方形面积 = r²，1/4 圆面积 = πr²/4
- 向正方形内**均匀随机投点**，落在 1/4 圆内的概率 = 圆面积 / 正方形面积 = **π/4**
- 因此：π ≈ 4 × (落在圆内的点数 / 总点数)

点 `(x, y)` 落在圆内的判定条件：`x² + y² < r²`

```python
import random

def count_inside(n):
    """统计 n 次投点中落在 1/4 圆内的次数（半径取 1）"""
    count = 0
    for _ in range(n):  # _ 作为占位符，表示这是一个不被使用的循环变量
        x, y = random.random(), random.random()   # [0,1) 内均匀随机投点
        if x*x + y*y < 1.0:                       # 落在圆内的判定
            count += 1
    return count

n = 1000000
pi = 4 * count_inside(n) / n
print(pi)          # 约 3.14 左右，n 越大越精确
```

### 一般步骤（答题模板）

1. **构造随机试验**：把问题转化为"随机投点 / 随机抽样"模型，明确样本空间
2. **大量重复试验**：用循环 + `random` 库生成大量随机样本
3. **统计计数**：数出满足条件的样本数
4. **频率代替概率**：`满足条件数 / 总数 ≈ 概率`，反推出所求量
