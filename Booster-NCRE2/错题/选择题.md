**1. 对以下代码的执行结果，描述正确的是**

```python
print((255>55) == true)
```

A. 输出 `true`
B. 输出 `False`
C. 输出 `True`
D. 出现错误: `NameError: name 'true' is not defined`

**答案：D**

**解析：**
- A：Python 的布尔值只有 `True`、`False` 两种写法，大小写敏感，`true` 是未定义的名字，不可能输出。
- B：`255 > 55` 成立，左侧值为 `True`，输出不会是 `False`。
- C：`True` 拼写正确，但代码中写的是小写 `true`，求值时先报错，不会输出 `True`。
- D：求值 `true` 时找不到该名字，抛出 `NameError: name 'true' is not defined`，正确。

**2. 关于函数局部变量和全局变量的使用规则，以下选项中描述错误的是**

A. 对于基本数据类型的变量，无论是否重名，局部变量与全局变量不同

D. `return` 不可以传递任意多个函数局部变量返回值

**答案：D**

**解析：**

- B：函数内用 `global` 声明后，对该变量的赋值作用于全局变量，表述正确。
- C：组合类型变量若在函数内未通过赋值创建同名局部变量，引用的是全局变量，表述正确。
- D：`return` 支持 `return a, b, c` 写法，可返回任意多个值（打包成元组），该项说法错误，为本题答案。

**23. 以下程序的输出结果是**

```python
s1 = "QQ"
s2 = "Wechat"
print("{:*<10}{:=>10}".format(s1, s2))
```

A. `********QQWechat====`
B. `QQWechat`
C. `QQ********====Wechat`
D. `Invalid format specifier`

**答案：C**

**解析：**

- C：`{:*<10}` 把 `QQ` 左对齐、右侧补 8 个 `*`，得 `QQ********`；`{:=>10}` 把 `Wechat` 右对齐、左侧补 4 个 `=`，得 `====Wechat`；拼接即 `QQ********====Wechat`，正确。
- D：`*`、`=` 是合法的填充字符，`<`、`>` 是合法的对齐符，该写法不会触发 `Invalid format specifier` 报错。

B. `TypeError: '>' not supported between instances of 'list' and 'str'`
C. `1`
D. `True`

**答案：D**

**解析：**
- A：第一个元素就能分出大小，结果不会是 `False`。
- B：只有比较到“列表与字符串”这类不可比较的类型对时才会抛 `TypeError`；本例第一个位置的两个元素都是字符串，可以正常比较。
- C：列表比较返回布尔值，不会返回数字。
- D：列表按位置依次比较，第一个元素 `'abc'` 与 `'1'` 不相等，立即比较二者大小；字符串按字符编码逐位比较，`'a'`（编码 97）大于 `'1'`（编码 49），`'abc' > '1'` 成立，结果为 `True`，后续元素不再比较。

**25. 以下程序的输出结果是**

```python
dat = ['1', '2', '3', '0', '0', '0']
for item in dat:
    if item == '0':
        dat.remove(item)
print(dat)
```

A. `['1', '2', '3']`
B. `['1', '2', '3', '0', '0']`
C. `['1', '2', '3', '0', '0', '0']`
D. `['1', '2', '3', '0']`

**答案：D**

**解析：**
- A：`['1', '2', '3']` 误以为三个 `'0'` 都会被删除；**边遍历边删除会漏删元素（重点是这句话！）** ，得不到该结果。
- B：`['1', '2', '3', '0', '0']` 只删掉一个 `'0'`，推演不完整。
- C：列表未删除任何元素，与 `remove` 会实际删除元素不符。
- D：for 循环按下标推进。下标 0、1、2 依次取到 `'1'`、`'2'`、`'3'`，不做处理；下标 3 取到 `'0'`，删除首个 `'0'` 后列表缩短为 5 个元素；下标 4 取到此时位于下标 4 的 `'0'`，再删一个；下标 5 已超出当前长度 4，循环结束，最终为 `['1', '2', '3', '0']`，正确。

**26. 关于数据维度的描述，错误的是**

A. 一维数据采用线性方式组织，对应于数组概念
B. 一维数据由键值对类型的数据组成，采用对象方式组织
C. 一维数据是由对等关系的有序数据构成，无序数据不是一维数据
D. 高维数据由键值对类型的数据组成，采用对象方式组织

**答案：C**

**解析：**
- A：一维数据采用线性方式组织，对应数组、集合等概念，表述正确。
- B：键值对类型的数据、对象方式组织是教材对高维数据的描述，“一维数据由键值对类型的数据组成”不成立（该项同样存在概念错误）。
- C：教材表述为一维数据由对等关系的**有序或无序**数据构成，无序数据（如集合表示的数据）也属于一维数据，“无序数据不是一维数据”与教材相悖，为官方答案。
- D：高维数据由键值对类型的数据组成、采用对象方式组织，表述正确。
- 注：本题源题有两个表述不准确的选项（B、C），官方口径以 C 为答案。

**27. 关于数据组织的维度描述正确的是**

A. 二维数据由对等关系的有序或无序数据构成
B. 高维数据由关联关系数据构成
C. CSV 是一维数据
D. 一维数据采用线性方式存储

**答案：D**

**解析：**
- A：对等关系、有序或无序数据是一维数据的特征；二维数据由关联关系数据构成、采用表格方式组织，该项混淆了两类描述。
- B：关联关系数据构成的是二维数据；高维数据由键值对类型的数据构成、采用对象方式组织，该项同样混淆。
- C：CSV 是二维数据的典型存储格式（每行是一维数据，整个文件是二维数据），“CSV 是一维数据”不成立。
- D：一维数据采用线性方式组织与存储，表述正确。

**28. 以下关于 Python 内置库、标准库和第三方库的描述，正确的是**

A. 第三方库需要单独安装才能使用
B. 内置库里的函数不需要 `import` 就可以调用
C. 第三方库有三种安装方式，最常用的是 `pip` 工具
D. 标准库跟第三方库发布方法不一样，是跟 Python 安装包一起发布的

**答案：D**

**解析：**
- A：“单独安装”的说法不成立：第三方库的安装方式多样（pip 工具、自定义、文件安装），依赖库可由 pip 自动安装，部分库还会随发行版（如 Anaconda）附带。
- B：“内置库”（如 `random`、`time` 这类随 Python 内置的库）中的函数同样需要 `import` 才能调用；可以不导入直接使用的是内置函数（如 `len`、`type`），两者含义不同。
- C：pip 是常用的第三方库安装工具，但“有三种安装方式、最常用的是 pip”属于对安装途径的过度限定，官方答案未采纳。
- D：标准库随 Python 安装包一起发布、无需单独安装，第三方库由第三方独立发布，发布方法不同，正确。
