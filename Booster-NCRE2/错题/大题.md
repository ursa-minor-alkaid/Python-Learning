**1. 0x4DC0 是一个十六进制数，它对应的 Unicode 编码是中国古老的《易经》六十四卦的第一卦，请输出第 51 卦（震卦）对应的 Unicode 编码的二进制、十进制、八进制和十六进制格式。**

```python
print("二进制{①}、十进制{②}、八进制{③}、十六进制{④}".format(⑤))
```

**答案**

```python
# ①:b ②:d ③:o ④:x ⑤:0x4DC0 + 50
# 六十四卦在 Unicode 中按卦序连续排列，第 51 卦编码为 0x4DC0 + 50 = 0x4DF2
print("二进制{:b}、十进制{:d}、八进制{:o}、十六进制{:x}".format(0x4DC0 + 50))
```

讲解：

- 第 1 卦编码为 `0x4DC0`，第 51 卦与它相差 50，编码即 `0x4DC0 + 50 = 0x4DF2`（十进制 19954）。
- 格式控制标记：`b` 二进制、`d` 十进制、`o` 八进制、`x` 十六进制（字母小写）。十六进制需要大写字母时改用 `X`，输出 4DF2。
- 运行结果：二进制100110111110010、十进制19954、八进制46762、十六进制4df2。

**2. 考生文件夹下存在 3 个 Python 源文件，分别对应 3 个问题，1 个文本文件，作为本题目输入数据，请按照源文件内部说明修改代码，实现以下功能：**

《命运》是著名科幻作家倪匡的作品。这里给出《命运》的一个网络版本文件，文件名为 `命运.txt`。

问题 1：在 `PY301_1.py` 文件中修改代码，对 `命运.txt` 文件进行字符频次统计，输出频次最高的中文字符（不包含标点符号）及其频次，字符与频次之间采用英文冒号 `:` 分隔，示例格式如下：

理:224

问题 3：在 `PY301_3.py` 文件中修改代码，对 `命运.txt` 文件进行字符频次统计，将所有字符按照频次从高到低排序，字符包括中文、标点、英文等符号，但不包含空格和回车。将排序后的字符及频次输出到考生文件夹下，文件名为 `命运-频次排序.txt`。字符与频次之间采用英文冒号 `:` 分隔，各字符之间采用英文逗号 `,` 分隔，参考 CSV 格式，最后无逗号，文件内部示例格式如下：

理:224,斯:120,卫:100

**答案**

源文件内已给出部分代码，下面为完整实现；考试时按源文件说明在对应位置补全统计、排序部分即可。

**问题 1**

```python
d = {}                                 # 记录每个字符出现的次数
f = open("命运.txt", "r")
for line in f:
    for ch in line:
        if "\u4e00" <= ch <= "\u9fff":  # 只统计中文字符，自动排除标点、英文、空格
            d[ch] = d.get(ch, 0) + 1
f.close()

ch = max(d, key=d.get)                 # 取频次最高的字符
print("{}:{}".format(ch, d[ch]))       # 输出格式示例：理:224
```

讲解：

- `d.get(ch, 0)` 在字符第一次出现时返回 0，实现计数累加。
- 判断中文字符采用 Unicode 区间 `\u4e00` 到 `\u9fff`（汉字基本区），无需逐个列出要排除的标点。
- `max(d, key=d.get)` 以字典值为比较依据，返回频次最高的键，即对应字符。

**问题 3**

```python
d = {}                                 # 记录每个字符出现的次数
f = open("命运.txt", "r")
for line in f:
    for ch in line:
        if ch != " " and ch != "\n":   # 排除空格与换行符
            d[ch] = d.get(ch, 0) + 1
f.close()

lst = sorted(d.items(), key=lambda x: x[1], reverse=True)  # 按频次从高到低排序
s = ",".join(["{}:{}".format(k, v) for k, v in lst])       # 拼接为一行
f = open("命运-频次排序.txt", "w")
f.write(s)
f.close()
```

讲解：

- 与问题 1 的差别在筛选条件：不限制字符种类，仅跳过空格和换行符。
- `d.items()` 得到 (字符, 频次) 元组；`key=lambda x: x[1]` 表示按第二个元素（频次）排序，`reverse=True` 表示降序。
- 列表推导式把每项格式化为 `字符:频次`，`",".join(...)` 只在元素之间插入逗号，结尾不会多出逗号。
- 排序结果以 `"w"` 模式写入 `命运-频次排序.txt`，内容为一行。
