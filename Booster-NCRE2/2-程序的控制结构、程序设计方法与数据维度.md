## 1. 程序的控制结构

任何程序都由三种基本控制结构组合而成：**顺序结构、分支结构、循环结构**（考纲"程序的控制结构"部分还包含异常处理 `try-except`）。

### 1. 顺序结构

代码从上到下逐行执行，没有跳转，是程序的默认执行方式。

### 2. 分支结构（选择结构）

根据条件真假选择执行不同的代码块。

- **单分支**：`if`
  
  ```python
  if 条件:
      <语句块>
  ```

- **二分支**：`if-else`
  
  ```python
  if 条件:
      <语句块1>
  else:
      <语句块2>
  ```

- **多分支**：`if-elif-else`
  
  ```python
  if 条件1:
      <语句块1>
  elif 条件2:
      <语句块2>
  else:
      <语句块3>
  ```

- 分支可以**嵌套**；
- 判断条件可用比较运算符、逻辑运算符（`and`、`or`、`not`）和成员运算符（`in`、`not in`）组合

### 3. 循环结构

重复执行某段代码

- **遍历循环** `for`：对序列（字符串、列表、range 等）逐个遍历
  
  ```python
  for 变量 in <序列>:
      <循环体>
  ```

- **条件循环（无限循环）** `while`：条件为真就一直执行
  
  ```python
  while 条件:
      <循环体>
  ```

- **循环控制**：
  - `break`：立即跳出**整个**循环
  - `continue`：跳过**本次**循环剩余语句，进入下一次循环

- **`else` 子句**（Python 特色，常考）：`for`/`while` 循环**正常结束**（没有被 `break` 中断）时执行 `else` 里的语句

### 4. 异常处理（控制结构的扩展）

```python
try:
    <可能出错的语句>
except <异常类型>:
    <出错后的处理>
```

常考异常类型：`ValueError`（值错误，如 `int("abc")`）、`TypeError`、`NameError`、`IndexError`、`FileNotFoundError` 等。

## 2. Python 程序设计方法

Python 是**多范式**语言，支持多种编程范式。考纲（2025 年版）点名五种程序设计方法：过程式、函数式、生态式、蒙特卡洛计算、递归计算。本节讲前三种，后两种见对应笔记（蒙特卡洛见 `4-蒙特卡洛方法.md`）。

### 1. 过程式编程方法

- 历史最悠久的编程范型，代表语言：机器语言、汇编语言；狭义上 C、Python 都属于过程式语言。
- 核心思想：**自顶向下、逐步求解**，用 **IPO 方法**组织程序：**输入（Input）→ 处理（Process）→ 输出（Output）**
- 第一部分的基本语法（顺序、分支、循环）正是过程式编程的体现。

### 2. 函数式编程方法

- 是**过程式编程的一个组成部分**（考纲/教材表述，选择题常考此归属关系）。
- 把"函数"作为运算的基本单位：函数可作参数传递、可作为结果返回，强调表达式求值而非语句执行。

### 3. 生态式编程方法

- Python 独有的编程思想：**不重复发明轮子**——直接复用 Python 计算生态中现成的标准库和第三方库来组建程序。
- 典型流程：分析需求 → 查找现有库 → `pip` 安装 → `import` 导入使用。
- 考纲要求的 turtle、random、time、jieba、PyInstaller 等库的使用，都是生态式编程的实践。

### *考试不要求的（补充）*

1. 面向对象编程（OOP） ：最"意外"的落选项。用类（class）封装数据和行为，三大特性：封装、继承、多态。这是 Python 最重要的主流范式之一
2. 声明式编程（Declarative） ：只描述"要什么"不描述"怎么算"，与过程式（命令式）相对。SQL 是最典型代表
3. 逻辑式编程 ：定义事实和规则，由引擎自动推理求解，代表语言 Prolog。写约束求解问题（如数独、排班）时很强大。
4. 并发/并行编程 ：asyncio 协程、多线程、多进程，关注"多条执行流如何协调"，是范式之外的横切主题。
5. 事件驱动编程 ：程序流程由外部事件（点击、消息）驱动，GUI 和网络服务器（如 Node.js 风格）的核心模型。
6. 切面式编程（AOP）、泛型编程、元编程 ：更工程向的进阶主题，了解名字即可。

## 3. 数据的维度：一维、二维与高维数据

读写文件时经常要处理结构化数据（如 CSV），理解"数据维度"有助于选择合适的存储结构和处理方式。

这里的"维度"指**数据的组织层次**，和空间几何的维度无关。

### 3.1 一维数据

- **定义**：由**一组相互独立的数据元素**排成一行（或一列）构成，只有一个"方向"，每个元素只有一个下标
- **Python 表示**：列表 `list`、元组 `tuple`
- **文件存储**：用**分隔符**把元素连接成一个字符串，一行即一条一维数据。CSV（Comma-Separated Values）就是典型：一行表示一维数据

### 3.2 二维数据

- **定义**：由**多行一维数据**构成，有"行、列"两个方向，每个元素需要两个下标（行号、列号）
- **Python 表示**：**嵌套列表**（列表的列表），如 `[[...], [...], [...]]`
- **文件存储**：整个文件就是"每行一条 CSV 记录"。表格（Excel 的一个工作表）、数据库的一张表都是二维数据
- **例子**：学生成绩表（行=学生，列=科目）、矩阵、图像像素表

  ```python
  table = [
      ['姓名', '语文', '数学'],   # 第 0 行（常作表头）
      ['小明', '90', '85'],       # 第 1 行
      ['小红', '88', '92'],       # 第 2 行
  ]
  # 访问：table[1][0] == '小明'（第 1 行第 0 列）
  # 写文件：每行 ','.join(row) + '\n'
  ```

### 3.3 高维数据

- **定义**：超过两维的数据，需要三个及以上下标定位一个元素，即"多维嵌套"
- **Python 表示**：多层嵌套列表，或（实践中）NumPy 的 `ndarray`、Pandas 的 DataFrame
- **例子**：
  - 三维：一个班级**每学期**的各科成绩（学生 × 科目 × 学期）；彩色图像（行 × 列 × RGB 三通道）
  - 更高维：视频（帧 × 行 × 列 × 通道）；气象数据（时间 × 纬度 × 经度 × 气压层）
- **文件存储**：纯文本 CSV 无法自然表达高维数据，通常的做法：
  - **降维存储**：把高维表"摊平"成二维（每行带多个索引列，类似数据库长表）
  - **专用格式**：JSON（嵌套结构天然支持多维）、HDF5、NetCDF（科学计算常用）、pickle（Python 序列化）
  - **多文件**：**一个切片存一个文件**，如每学期一个 CSV
- **推荐写法**：多维数据可以用类似json的缩进方式表示

### 3.4 用嵌套循环处理二维数据

二维数据 = 行的列表，所以**外层循环遍历行，内层循环遍历行内的元素**——数据有几个维度，循环就嵌套几层：

```python
table = [
    ['姓名', '语文', '数学'],
    ['小明', '90', '85'],
    ['小红', '88', '92'],
]

# 遍历：逐行 → 行内逐元素
for row in table:          # 外层：每次拿到一整行（一维数据）
    for item in row:       # 内层：每次拿到一个元素
        print(item, end=' ')
    print()                
    # 每行结束后换行（默认的 print 相当于打印一个换行符）

# 典型统计：求每行（每个学生）的总分
for row in table[1:]:      # 跳过表头
    total = 0
    for score in row[1:]:  # 跳过姓名列
        total += int(score)
    print(row[0], total)   # 小明 175 / 小红 180
```

**配合文件读写，就是处理 CSV 的标准模式：**

```python
with open('scores.csv', encoding='utf-8') as f:
    table = [line.strip().split(',') for line in f]   # 读入 → 二维列表

for row in table:                                     # 嵌套循环逐行逐列处理
    ...

with open('out.csv', 'w', encoding='utf-8') as f:
    f.writelines(','.join(row) + '\n' for row in table)  # 写回
```

### 3.5 高维数据处理

规律顺延：**几维数据就嵌套几层循环**（三维 = 三重循环），或改用更合适的工具：

- **多层嵌套循环**（纯 Python，数据量小才用）：

  ```python
  # 三维数据 data[i][j][k]：学期 × 学生 × 科目
  for i, term in enumerate(data):        # 第 1 层：切片（学期）
      for j, row in enumerate(term):     # 第 2 层：行（学生）
          for k, val in enumerate(row):  # 第 3 层：列（科目）
              print(i, j, k, val)
  ```

- **NumPy 向量化运算**（实践首选）：不写循环，对整个数组一次性操作，`axis` 参数指定沿哪个维度计算：

  ```python
  import numpy as np
  arr = np.array(data)   # 形状 (学期数, 学生数, 科目数)
  arr.mean(axis=2)       # 沿"科目"轴求均值 → 每人每学期的平均分
  ```

- **降维拆解**：把高维拆成"一系列二维切片"，每个切片用双循环处理，或存成一个 CSV 文件——本质是**用文件组织来代替第 3 层维度**（如 `2024春.csv`、`2024秋.csv` 各存一个二维表）
- **换数据结构**：嵌套字典（按标签索引，如 `scores['小明']['数学']`）比位置下标更直观；二维表格用 pandas DataFrame，更高维用 xarray

- 一维 → 单层循环；二维 → 嵌套双层；高维 → 层数顺延，但实际工程中几乎总是交给 NumPy / pandas / xarray 处理，而不是手写多重循环。
