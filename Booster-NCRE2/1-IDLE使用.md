# IDLE 使用

时间：`2026年9月5日`

## IDLE

### IDLE 介绍

IDLE（**I**ntegrated **D**evelopment and **L**earning **E**nvironment，集成开发与学习环境）是 Python **官方自带**的集成开发环境，随 Python 安装包一同安装，无需额外配置即可使用。

- **出身**：由 Python 创始人 Guido van Rossum 参与开发，1998 年首次发布；用 100% 纯 Python（基于 `tkinter` GUI 工具包）编写，源码位于标准库 `Lib/idlelib/` 中
- **定位**：专为初学者和教学设计的轻量级 IDE，功能不如 PyCharm、VS Code 丰富，但覆盖了写代码、运行、调试的全部基本需求
- **跨平台**：在 Windows、macOS、Linux 上表现基本一致

IDLE 包含两类窗口：

| 窗口 | 说明 |
| --- | --- |
| **Shell 窗口**（交互式解释器） | 输入一条执行一条，立即显示结果，输入输出和错误信息带颜色高亮；适合快速试验代码片段 |
| **Editor 窗口**（编辑器） | 多窗口文本编辑器，支持语法高亮、智能缩进（默认 4 空格）、函数调用提示、自动补全、多次撤销；程序写好后在此运行（`f5`） |

此外 IDLE 还内置**调试器**（断点、单步执行、查看变量）和多文件搜索等功能。

### IDLE 常规操作

- 创建新文件：快捷键 `ctrl + n` 或者点击左上角新建
- 保存：快捷键 `ctrl + s` 或者点击左上角保存
- 打开：快捷键 `ctrl + o` 或者点击左上角打开
- 运行：快捷键 `f5` 或者点击键 `Run`（会在 shell 中运行）

## 考试事项

- 考试环境固定：**Windows 7 + Python 3.5.3 ~ 3.9.10**，**只能使用 IDLE** 作为开发环境，不能安装其他 IDE
- 考纲基本要求："熟练使用 IDLE 开发环境，能够将脚本程序转变为可执行程序"
- 选择题中的程序代码**不能用 IDLE 运行验证**，进入操作题阶段键盘才解锁
- **F5 运行前必须先保存**：未保存的文件按 F5 会弹出"保存"对话框，务必先保存到**考生文件夹**再运行
- **缩进**：IDLE 默认 4 空格缩进，Tab/空格混用或缩进不一致会触发 `IndentationError`；Shell 窗口中多行代码需输入完再按一次空回车结束
- 题目引用的文件会放在考生文件夹中，注意相对路径
